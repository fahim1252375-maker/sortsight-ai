# Support

Thanks for using SortSight AI.

## Before asking for help

1. Read [README.md](./README.md) and the Bengali [START-HERE guide](./START-HERE-BN.md).
2. Review the relevant documents in the docs directory.
3. Search [existing issues](https://github.com/fahim1252375-maker/sortsight-ai/issues) for an existing answer.

## Report a bug

Use the [Bug report form](https://github.com/fahim1252375-maker/sortsight-ai/issues/new?template=bug_report.yml). Include reproducible steps and sanitized logs.

## Request a feature

Use the [Feature request form](https://github.com/fahim1252375-maker/sortsight-ai/issues/new?template=feature_request.yml).

## Security concerns

Do not disclose exploitable vulnerabilities, credentials, API keys, or private user data in public issues. Follow the private reporting instructions in [docs/SECURITY.md](./docs/SECURITY.md) and GitHub's Report a vulnerability flow when available.
